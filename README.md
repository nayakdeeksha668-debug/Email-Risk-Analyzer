
# Email Risk Analyzer

## Project Description
Email Risk Analyzer is a Python-based application
that scans email messages and identifies
potentially suspicious content.

## Features
- Suspicious keyword detection
- Risk score calculation
- Low, Medium and High risk classification
- URL detection
- Automatic report generation

## Technologies Used
- Python
- Regular Expressions
- Visual Studio Code

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run: python email_analyzer.py
5. Enter an email message.

## Output
The program displays the risk analysis
and saves the result in email_report.txt.

## Disclaimer
This is a basic educational tool.
It does not guarantee detection of all
phishing or malicious emails.
